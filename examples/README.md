# Examples

Worked dark factories generated by (and for) the Dark Forgery skill. Each is a **complete,
runnable scaffold** — the kind of output the skill produces from a one-line idea — and doubles
as an **extension point**: when we refine an example and the improvement is general to *all*
factories, it gets distilled back into `SKILL.md` / `references/`.

Together the examples are chosen to cover the whole skill surface — no two share the same
execution environment, logging destination, auth mode, or spawning model:

| Example | Idea | Exec env | Logging | Auth | Spawning | Roles |
|---|---|---|---|---|---|---|
| [`feed-digester`](feed-digester/) | RSS/newsletter → daily briefing | Docker | Plain markdown (git) | OAuth (Max) | Sequential | Editor · Engineer · QA |
| `uptime-monitor` *(planned)* | Endpoint prober + status dashboard | Docker + compose | GitHub Issues | API key | Parallel (worktrees) | + Designer |
| `scrape-pipeline` *(planned)* | Scheduled scraper → versioned dataset | Remote server | Obsidian vault | OAuth | Sequential | + Data Engineer |

A fourth idea (`figma-to-components`, a host-machine CLI) is intentionally **not** built here —
it is reserved as an unseen acceptance test for the finished skill.

## Validating an example

Every example must pass the scaffold checker:

```bash
scripts/check_scaffold.sh examples/feed-digester
```

## Linking from the skill

`SKILL.md` and `references/` link into these examples at the exact points where a concrete
artifact disambiguates an instruction (e.g. "for a worked entrypoint with hang protection and
the crash-loop alert, see `examples/feed-digester/scripts/editor_entrypoint.sh`").
